# React интенсив

Создание приложения для отображения постов, с комментариями.
Есть возможность доступа в личный кабинет пользователя, откуда есть доступ к его постам, альбомам и задачам. В качестве источника данных используется https://jsonplaceholder.typicode.com/

### Технологии

- React
- TypeScript 
- RTK, RTK Query
- React Router Dom

## Работа с проектом

1. Склонировать [репозиторий фронтенда](https://github.com/ZaytsevAlexanderGit/aston_react_homework_1)
   ```shell
   git clone https://github.com/ZaytsevAlexanderGit/aston_react_homework_1
   ```
2. Установить зависимости **именно** `npm ci`

   ```shell
   npm i
   ```

3. Запустить скрипт фронтенда и storybook в concurrent режиме

   ```shell
   npm run dev
   ```

5. Фронтенд доступен на `PORT` (по умолчанию http://localhost:5173)
